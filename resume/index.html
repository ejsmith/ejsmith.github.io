Distinguished Engineer · Concord Finance

2023 – Present

Credit administration servicing and software for specialty finance; $60B+ in assets under administration.

  • Led the greenfield build of Concord Link, the loan, lease and line-of-credit servicing platform replacing a green-screen system that ran the business for 40+ years. With almost no documented requirements, learned how servicing really worked from the people doing it and designed a configurable platform rather than a single-vertical product, so the business can grow into new markets without starting over. Now live with clients.
  • Designed and built the scripting engine and durable workflows (on Jint) that turn each client's business rules for payment allocation, fees, interest, statements and collections into configuration instead of engineering releases. Workflows wait days for an account event and resume with deterministic replay; released the core as open-source Jint.Workflows.
  • Designed and built the configurable import/export pipeline that turned client onboarding and legacy migration into setup work: declarative mappings with scripted transforms; CSV, Excel, XML and JSON; PGP, SFTP and S3; scheduling and record-level error handling.
  • Architected the multi-tenant .NET and SvelteKit platform on AWS, and set the engineering bar for a team of 20+ through architecture, mentoring and 1,500+ code reviews.
  • Led the team's AI adoption: an AI code-review pipeline (five specialist reviewers, evals and cost telemetry; 1,000+ PRs reviewed), a permission-scoped MCP server so staff can use AI with live data, and shared agent guidelines, skills and UI verification.
